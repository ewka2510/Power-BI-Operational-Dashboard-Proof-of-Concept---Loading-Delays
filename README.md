# Power-BI-Operational-Dashboard-Proof-of-Concept-Loading-Delays

## Project Overview
This project demonstrates a **Power BI dashboard** designed to support operational analysis and decision-making. It visualizes key metrics and allows users to explore the data through **interactive charts, slicers, and drill-downs**.

---

## Data Transformation Highlights

- Remove unnecessary columns and filter rows  
- Split datetime columns into separate Date and Time fields  
- Rename columns for clarity  
- Add calculated metrics (e.g., delay between scheduled and actual arrivals)  

---

## Dashboard Features

- Interactive charts and visuals for operational metrics  
- Slicers for filtering by key attributes  
- Drill-down and tooltip functionality  
- Metrics include arrivals, departures, carrier performance, and delays  

---

## Purpose

This is a **proof-of-concept dashboard** showing how operational data can be transformed and presented interactively. It can be extended for tailored analysis and decision support.
